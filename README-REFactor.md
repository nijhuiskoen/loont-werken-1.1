# Loont-werken V21

V21 maakt van de oorspronkelijke monolithische App.jsx een schaalbare structuur met:

- homepage en calculatoroverzicht;
- losse pagina voor Meer/minder werken;
- gescheiden berekeningslaag;
- jaargebonden data voor 2026;
- centrale officiële bronnen;
- lazy loading van de calculatorpagina;
- Vercel SPA fallback;
- automatische dagelijkse controle van officiële bronpagina's.

Zie `README-DATA-UPDATES.md` voor de updateworkflow.
